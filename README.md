# PatchInsta

Patch Piko expérimental pour adapter les Réels Instagram aux fenêtres étroites et larges des Galaxy Fold.

La compilation GitHub Actions produit `piko-fold-reels-experimental.mpp`, à importer comme source locale dans Morphe. Le rendu sur appareil reste à valider.

Voir [le guide français](GUIDE-FR.md) et [les compilations](https://github.com/senor-roboto/PatchInsta/actions).

Basé sur Piko, sous GPL-3.0-or-later. Modification non officielle.
